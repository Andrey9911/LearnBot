# LearnBot

Стартовый каркас Telegram-бота для практического английского.

## Запуск

1. Установить зависимости: `npm install`.
2. Создать `.env` на основе `.env.example`.
3. Запустить бота: `npm start`.

На текущем этапе реализованы только интерфейс онбординга и маршрутизация FSM. Интеграции OpenRouter, Supabase, планировщик и бизнес-логика оставлены как следующие этапы.
